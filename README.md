# BioFlexFitness Landing Page

A static, mobile-responsive landing page for BioFlexFitness (Pty) Ltd.

## Files
- `index.html` — page content and SEO metadata
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation, reveal animations, current-year footer
- `favicon.svg` — browser icon

## Free deployment options
### Cloudflare Pages
1. Put these files in a GitHub repository.
2. In Cloudflare Pages, connect the repository.
3. Framework preset: None.
4. Build command: leave blank.
5. Build output directory: `/`.
6. Deploy.

### Netlify Drop
Drag the entire `bioflex-landing` folder into Netlify Drop.
